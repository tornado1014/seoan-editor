# 서안 화면 디자인 — 書案(글 쓰는 책상)

## 개념
- **생각**: 서안(書案)은 글 쓰는 책상이다. 앱은 정돈된 책상이고, 그 위에 종이(쪽) 한 장이 놓인다.
- **빌려 온 세계**: 오동나무 책상 · 한지 · 먹 · 낙관의 주칠.
- **한 번의 순간(signature)**: **낙관 찍기**. 저장 · 제출파일 · 보정서가 끝나면 상태 줄 옆에 붉은 「書案」 낙관이 한 번 찍힌다(살짝 기울어 내려앉고 2초쯤 뒤 스민다). 알림 글은 상태 줄(`aria-live`)이 하고, 낙관은 장식(`aria-hidden`)이다.
- **움직임 동사**: **종이가 책상에 내려앉는다**. 떠 있는 창은 위에서 4px 내려오며 나타나고, 단추는 누르면 1px 내려앉는다.
- **멈춰 있을 때**: 하루 종일 쓰는 도구라 쉴 때는 가만히 있는다(의도한 결정). 깜박이는 커서 곁에서 다른 것이 움직이면 방해된다. 생기는 올림 · 누름 · 낙관이 맡는다.
- **찍어 둘 화면**: 빈 책상. 왼쪽에 세로로 쓴 「書案」과 주칠 네모, 오른쪽에 「열기 ⌘O」 · 「워드/XML로 HLT 만들기」 · 「새 의견서」.

## 맥 앱 결 — Things 3 · Bear 를 본뜸 (2차)
- **Things 3**:
  - 구조 창은 차분한 회색 사이드바다. 점선 가지 대신 들여쓰기와 꺾쇠로 접는다.
  - 지금 자리는 둥근 강조 알약으로 보인다.
  - 툴바는 상자도 선도 없이 간격으로만 묶는다. 묶음 이름은 화면에서 감추고 투어와 낭독기용 `aria-label`로만 남긴다.
  - ⌘K 명령 찾기는 Spotlight처럼 큰 입력 한 줄과 꽉 찬 선택 줄이다.
- **Bear**:
  - 종이 뒤 바탕은 밝은 아이보리이고, 종이는 가는 가장자리와 긴 그림자를 가진다.
  - 강조색은 Bear의 빨강이다. 서안 주칠과 같은 결이다.
- 창은 맥 시트(sheet)처럼 만든다. 테두리 대신 0.5px 고리와 깊은 그림자를 쓴다. 기본 단추는 강조색 채움, 나머지는 흰 바탕에 가는 테다. 묶음 상자 대신 제목과 위 선을 쓴다.
- 스크롤 막대는 가늘고 둥글다.
- 맥 통합 제목 막대(`titleBarStyle: Overlay`)는 쓰지 않는다. 다음과 부딪히기 때문이다.
  - 네이티브 탭(`tabbingIdentifier`)
  - 끌기 영역 권한(`core:default`)
  - 윈도우 판

## 색 (토큰은 `src/styles.css` `:root`)
| 역할 | 낮 | 밤 |
|---|---|---|
| desk(종이 뒤 바탕) | `#f6f4ef` | `#1a1a1a` |
| chrome(툴바 · 창) | `#ffffff` | `#262626` |
| sidebar(구조 창) | `#faf8f4` | `#1e1e1e` |
| surface(떠 있는 창 · 칸) | `#ffffff` | `#2f2f2f` |
| ink | `#1d1d1f` | `#f2f2f2` |
| muted | `#636366` | `#a1a1a6` |
| line | `rgba(0,0,0,.1)` | `rgba(255,255,255,.1)` |
| accent(아이콘 · 초점 고리) | `#e5483e` | `#ff6b5e` |
| accent-ink(채움 · 글자, 흰 글자와 AA) | `#a82d26` | `#ff8a7f` |

- 낮 바탕은 회색이 아니라 밝은 아이보리이고, 구조 창 아이콘은 제 색을 낸다(사용자 「너무 차분하다 · 더 밝게」).
- 밤에는 바탕과 도구만 어두워진다. **종이(쪽)는 늘 흰 종이**다.
- ⛔ 쪽 위 그림(`.nk-*`: 글자 · 밑줄 · 커서 · 고른 구간 · 보정 표시)은 통특기와 맞춘 정답이라 토큰을 타지 않는다.
- 흰 글자를 밝은 빨강(`#e5483e`) 위에 두면 대비가 4:1로 AA에 못 미친다. 그래서 채움은 늘 `accent-ink`를 쓴다.

## 글꼴 · 모양
- UI 글꼴은 SF(`-apple-system`), 그다음 `Apple SD Gothic Neo` · `Malgun Gothic`이다. 오프라인 앱이라 웹폰트는 없다. 굵기는 400 · 500 · 600만 쓴다.
- 표제 · 시작 화면 글은 시스템 명조다(`AppleMyungjo`, `Noto Serif KR`, `Batang`).
- 글자 크기: UI 13px · 작은 이름 10.5~12px · 창 제목 15px.
- 한국어는 어절 단위로 줄을 바꾼다(`word-break: keep-all`).
- 둥글기: 단추 6px · 시작 단추 9px · 창 12px · 명령 찾기 14px · 낙관 3px.
- 그림자: `--lift-1`(떠 있는 작은 것) · `--lift-2`(창) 두 가지만 쓴다.
- 움직임: `--ease` 하나(`cubic-bezier(.2,.7,.2,1)`), 120ms(손끝) · 180ms(창).
- 줄인 움직임(`prefers-reduced-motion`)에서는 낙관이 움직이지 않고 그 자리에 나타났다 사라진다.

## 손이 닿는 것
- 올리면 옅은 바탕에 아이콘이 주칠로 바뀐다.
- 누르면 1px 내려앉는다.
- 키보드 초점은 주칠 2px 고리다.
- 눌린 상태(`aria-pressed`)는 주칠 옅은 바탕이다(문단부호만 쪽빛).
- 창 아래 단추는 한 줄 오른쪽에 둔다. 취소가 왼쪽, 할 일이 오른쪽 끝이다.
